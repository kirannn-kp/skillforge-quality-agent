# Project conventions

This is a synthetic, local-first demonstration, not a production quality system.
Use shared TypeScript contracts. Keep approval enforcement on the server.
Never silently replace connected services with mocks. Image observations are
advisory; no production release, hold or calibration changes are automated.
Run `npm run typecheck`, `npm run lint`, `npm test`, `npm run build` and focused
browser tests after relevant code changes. Never include credentials or real
factory data. The skill provenance is explicitly synthetic until a reviewed
export is supplied.

If you are in VS Code, read the vscode-microsoft-foundry skill first.

# Vehicle Quality Investigation

## Purpose

Apply a consistent, evidence-led investigation procedure. This synthetic example
illustrates a reviewed Skill Recorder export; it is not a recording of a real expert.

## Procedure

1. Capture issue, vehicle, plant, production line, station, component, symptom, first-observed time and scope.
2. Assess severity and determine whether a human must evaluate immediate containment.
3. Collect relevant visual evidence with the operator's consent.
4. Treat visual analysis as advisory observations; never infer dimensions or calibration from a photograph.
5. Retrieve production measurements before and after the reported start time.
6. Retrieve station maintenance, tool-change and calibration events.
7. Search approved engineering knowledge and similar historical incidents.
8. Separate facts, observations, correlations and hypotheses; disclose missing or conflicting evidence.
9. Form a probable-cause hypothesis only after production and maintenance retrieval succeeds.
10. Retrieve an approved corrective procedure; do not invent a historical match if none exists.
11. Prepare a corrective-action request without executing it.
12. Obtain explicit human approval before creating or routing the request.
13. Never change calibration, place or remove a hold, release production, or close an issue automatically.
14. Record evidence citations, skill version, tool calls and approvals for auditability.

## Required human approvals

- Creating or routing a corrective-action record
- Placing or removing a production hold
- Changing a calibration profile
- Releasing a station or vehicle
- Closing a quality issue

## Output

Return investigation summary, cited evidence, visual limitations, production and
maintenance correlation, historical search result, probable cause, recommended
checks, required approvals and the action result. Use calibrated language, not
arbitrary numerical confidence. No production release is authorized by this skill.
